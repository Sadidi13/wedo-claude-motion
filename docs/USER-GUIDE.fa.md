# راهنمای کاربری WeDo Claude Motion (فارسی)

> ویرایشگر لایه‌محور برای انیمیشن‌های Claude Motion / Claude Design

---

## ۱. راه‌اندازی

برای نصب ساده (با Claude Code یا یک خط در PowerShell) فایل [`README.fa.md`](../README.fa.md) را ببین.
بعد از نصب، در ویندوز روی میان‌بُر **WeDo Claude Motion** روی دسکتاپ دوبار کلیک کن.

اگر خودت از روی کد اجرا می‌کنی:

```bash
pnpm install
cp .env.example .env.local      # اختیاری: کلید API فقط اگر از Claude Desktop استفاده نمی‌کنی
pnpm dev                        # http://localhost:3000
```

| نیازمندی | توضیح |
|---|---|
| Node 22+ و pnpm | اجرای برنامه |
| Chrome / Edge نصب‌شده | برای Export؛ خودکار پیدا می‌شود (در صورت نیاز `CHROMIUM_PATH`) |
| ffmpeg | همراه پروژه نصب می‌شود (`ffmpeg-static`)؛ نیازی به نصب جدا نیست |
| `ANTHROPIC_API_KEY` | اختیاری؛ فقط اگر بخواهی تب «Ask Claude» به‌جای Claude Desktop از API استفاده کند |

> کلید API فقط سمت سرور خوانده می‌شود و هیچ‌وقت به مرورگر نمی‌رود.

## ۲. گرفتن کد از Claude (به‌جای MP4)

| کجا ساخته‌ای | چه چیزی بگیر | در Motion Studio |
|---|---|---|
| Claude Design | Share → Export → **Project archive (.zip)** | Import → فایل zip را بینداز |
| Claude Design | Share → Export → **Standalone HTML** | Import → فایل html |
| Claude Motion (چت) | بنویس: «کد HTML/JSX کامل همین انیمیشن را بده» و ذخیره کن | Import → فایل html یا jsx |
| پلن Team نداری | تب Ask Claude → حالت **New scene** → توضیح بده | همین‌جا ساخته می‌شود |

**مثال پرامپت در چت Claude:**
> «این انیمیشن را به‌صورت یک فایل HTML کامل با همان `animations.jsx` (Stage/Sprite) به من بده تا در ویرایشگر لایه‌ای بازش کنم.»

فایل MP4 قابل تبدیل به لایه نیست.

## ۳. اتصال به Claude Desktop (بدون کلید API)

با اشتراک Claude (مثلاً Max) می‌توانی بدون کلید API از Claude در برنامهٔ دسکتاپ استفاده کنی. Claude و ویرایشگر در دو جهت به هم وصل‌اند.

**پیش‌نیاز:** برنامه روشن باشد (میان‌بُر روی دسکتاپ، یا `pnpm dev`) و صفحهٔ `http://localhost:3000` در مرورگر باز باشد. در تب Code برنامهٔ Claude، پوشهٔ همین پروژه را باز کن. اگر برنامهٔ Claude را وصل کرده باشی (پایین‌تر، «از چت معمولی Claude»)، هر پوشه‌ای کار می‌کند.

### اتوپایلوت: جواب خودکار به تب Ask Claude (پیشنهادی)
اتوپایلوت یک پنجرهٔ کوچک است که همیشه گوش می‌دهد و هر دستوری را که در تب Ask Claude بنویسی، خودش با Claude انجام می‌دهد. لازم نیست هیچ چت یا سشنی باز باشد.

1. در File Explorer روی `scripts\start-autopilot.cmd` دوبار کلیک کن.
2. بار اول از تو می‌خواهد در مرورگر با حساب Claude وارد شوی. با همان حسابی وارد شو که اشتراک Max دارد. این کار فقط یک بار لازم است.
3. وقتی پنجره نوشت «Listening»، آماده است. در تب Ask Claude بالای پنل، کلمهٔ **Autopilot** با نقطهٔ سبز را می‌بینی.
4. دستورت را در Motion Studio بفرست. چند ثانیه تا یک دقیقه بعد تغییر خودکار اعمال می‌شود.

- **مصرف:** تا وقتی دستوری نفرستی هیچ مصرفی ندارد، چون فقط از Motion Studio روی کامپیوتر خودت می‌پرسد «درخواست جدید هست؟». هر دستور یک بار کوتاه از Claude استفاده می‌کند و از سهمیهٔ اشتراکت کم می‌شود.
- برای خاموش کردن، پنجرهٔ اتوپایلوت را ببند.
- هم‌زمان فقط یکی گوش بدهد: یا اتوپایلوت، یا یک سشن Claude که به آن گفته‌ای «به موشن استودیو گوش بده».

### از چت به ویرایشگر
- در چت بنویس، مثلاً: «یک تیزر ۶ ثانیه‌ای برای معرفی محصول بساز».
- Claude صحنه را لایه‌به‌لایه می‌نویسد. اگر سرور خاموش باشد خودش روشنش می‌کند، و اگر ویرایشگر در مرورگر باز نباشد، مرورگر خودکار روی `localhost:3000` باز می‌شود و صحنه همان‌جا لود می‌شود. اگر ویرایشگر باز باشد، صحنه چند ثانیه بعد در همان تب ظاهر می‌شود.
- آخر جواب، Claude یادآوری می‌کند که برای تغییر، دستورت را در تب Ask Claude بنویسی و بعد در چت بنویسی «کلاد موشن رو چک کن»، یا اتوپایلوت را باز بگذاری تا تغییرها خودکار انجام شوند.
- برای تغییر همان صحنه هم در چت بنویس، مثلاً: «عنوان را بزرگ‌تر کن». تغییر روی پروژهٔ باز اعمال می‌شود و با یک Undo برمی‌گردد.

### از ویرایشگر به چت
1. یک بار در چت بنویس: «به موشن استودیو گوش بده».
2. در ویرایشگر لایه را انتخاب کن، تب **Ask Claude** را باز کن و دستور را بنویس.
3. درخواست به همان سشن Claude می‌رسد، Claude جواب می‌دهد و تغییر خودکار در ویرایشگر اعمال می‌شود.

| وضعیت در تب Ask Claude | معنی |
|---|---|
| Claude Desktop (سبز) | Claude در حال گوش دادن است |
| Claude Desktop · busy | Claude روی درخواست تو کار می‌کند |
| Claude Desktop · between requests | Claude جواب قبلی را داد و الان دوباره گوش می‌دهد |
| Claude Desktop · offline | کسی گوش نمی‌دهد؛ درخواست‌ها در صف می‌مانند تا در چت بگویی «به موشن استودیو گوش بده» |

- با دکمهٔ **Cancel** می‌توانی درخواستی را که هنوز جواب نگرفته لغو کنی.
- اگر کلید API هم گذاشته باشی، تیک **Use API key** درخواست را به‌جای Claude Desktop به API می‌فرستد.
- گوش دادن تا وقتی سشن Claude باز است ادامه دارد. اگر سشن را بستی، در سشن جدید دوباره بگو «به موشن استودیو گوش بده».

### از چت معمولی Claude (تب Chat)
چت معمولی نمی‌تواند دستور اجرا کند، پس از طریق یک کانکتور MCP به Motion Studio وصل می‌شود.

**راه‌اندازی، فقط یک بار:**
1. در File Explorer روی فایل `scripts\connect-claude-chat.cmd` در پوشهٔ پروژه دوبار کلیک کن. یک پنجرهٔ سیاه باز می‌شود و منتظر می‌ماند.
2. برنامهٔ Claude را کامل ببند: روی آیکن Claude کنار ساعت ویندوز راست‌کلیک کن و Quit را بزن.
3. پنجره خودش ادامه می‌دهد: کانکتور را ثبت می‌کند، اگر Motion Studio خاموش باشد آن را در یک پنجرهٔ جدا روشن می‌کند و Claude را دوباره باز می‌کند. پنجرهٔ Motion Studio را باز بگذار.
4. در یک چت جدید باید کانکتور **motion-studio** را در فهرست ابزارها ببینی.

> چرا باید Claude بسته باشد؟ برنامهٔ Claude تا وقتی باز است تنظیماتش را در حافظه نگه می‌دارد و موقع ذخیره، روی فایل تنظیمات می‌نویسد. پس تغییری که در همان زمان اضافه شود پاک می‌شود.

**استفاده:**
- **ساختن و ویرایش:** در چت بنویس «یک تیزر ۶ ثانیه‌ای بساز» یا «عنوان را قرمز کن». Claude صحنه را در Motion Studio می‌سازد یا روی پروژهٔ باز اعمال می‌کند. اگر سرور خاموش باشد، خودش آن را روشن می‌کند.
- **گوش دادن:** بنویس «به موشن استودیو گوش بده». Claude هر بار تا ۴۵ ثانیه منتظر می‌ماند و به محض اینکه از تب Ask Claude دستوری بفرستی، جوابش را می‌دهد و دوباره منتظر می‌ماند. اگر بعد از مدتی متوقف شد، بنویس «ادامه بده».
- **بررسی صف:** اگر Claude گوش نمی‌داد، دستورت را در Motion Studio بفرست و بعد در چت بنویس «کلاد موشن رو چک کن». همهٔ درخواست‌های صف انجام می‌شوند.

> تفاوت: سشن تب Code می‌تواند بی‌وقفه و در پس‌زمینه گوش بدهد. چت معمولی فقط وقتی گوش می‌دهد که خودش در حال کار باشد.

جزئیات فنی: `docs/CLAUDE-DESKTOP.md`.

## ۴. نقشهٔ صفحه

```
┌ نوار بالا: نام پروژه · Storyboard · Check · History · Import · Export · Save · Undo/Redo ┐
├───────────┬──────────────────────────────────┬──────────────────────────┤
│ Layers    │  Canvas (پیش‌نمایش زنده)          │ Inspector                │
│ درخت لایه‌ها│  کلیک = انتخاب لایه               │  Properties / Code /     │
│ + Text    │                                  │  Ask Claude              │
│ + Image   │                                  │                          │
│ + Shape   │  Comment (C) = کامنت روی تصویر    │                          │
│ + Sound   │  دستگیره‌ها = جابه‌جایی/اندازه/چرخش │                          │
├───────────┴──────────────────────────────────┴──────────────────────────┤
│ Timeline: خط‌کش، playhead، یک ردیف برای هر لایه، نوار هر Sprite قابل درگ │
└─────────────────────────────────────────────────────────────────────────┘
```

- **ترتیب لایه‌ها** مثل After Effects است: لایه‌ای که بالاتر در پنل است، روی بقیه کشیده می‌شود.
- آیکن چشم = مخفی کردن (`data-hidden`)، قفل = جلوگیری از ویرایش تصادفی.
- دابل‌کلیک روی نام = تغییر نام (در کد به‌صورت `data-layer-name` ذخیره می‌شود).

## ۵. کارهای روزمره

### ۴.۱ تغییر زمان‌بندی
- در تایم‌لاین نوار Sprite را بکش (جابه‌جایی) یا لبه‌هایش را بکش (trim). به فریم snap می‌شود و از بازهٔ والد بیرون نمی‌رود.
- یا در تب Properties عدد Start/End را بنویس.
- لایه‌ای که Sprite نیست (مثلاً یک `<div>` داخل یک Sprite) زمان والدش را ارث می‌برد؛ با دکمهٔ **Wrap in Sprite** می‌شود زمان مستقل داد.

### ۴.۲ افزودن لایه
- **+ Text / + Image / + Shape** یک Sprite دو ثانیه‌ای در محل playhead می‌سازد.
- بعد می‌توانی همان لایه را انتخاب کنی و با Ask Claude بگویی: «این را یک lower-third شیک کن با انیمیشن ورود از چپ».

### ۴.۳ اصلاح با Claude (نکتهٔ اصلی محصول)
1. لایه را انتخاب کن (پنل، تایم‌لاین یا کلیک روی بوم).
2. تب **Ask Claude** → حالت **Selected layer**.
3. پرامپت بنویس (فارسی هم می‌شود). مثال‌ها:
   - «عنوان ۰٫۳ ثانیه دیرتر بیاید و با easeOutBack بالا بیاید»
   - «رنگ کارت‌ها را به پالت بنفش/فیروزه‌ای تغییر بده و سایهٔ نرم اضافه کن»
   - «متن را فارسی کن: «معرفی نوا» با فونت Vazirmatn و راست‌چین»
4. فقط همان لایه عوض می‌شود؛ بقیهٔ کد بایت‌به‌بایت ثابت می‌ماند. اگر نتیجه را نخواستی: **Undo**.

حالت **Whole scene** برای تغییرات کلی (پالت، ریتم، ترتیب صحنه‌ها) و حالت **New scene** برای ساخت از صفر
(که با استوری‌بورد شروع می‌شود، بخش ۴.۷).

### ۴.۴ ویرایش دستی کد
تب **Code** کد همان لایهٔ انتخاب‌شده را نشان می‌دهد؛ تغییر بده و Apply بزن. با سوییچ «whole scene» کل فایل را می‌بینی. خطای نحوی همان‌جا نمایش داده می‌شود و چیزی خراب نمی‌شود.

### ۴.۵ خروجی گرفتن
| فرمت | کاربرد | آلفا |
|---|---|---|
| MP4 (H.264) | اینستاگرام، سایت، پرزنتیشن | ندارد |
| WebM (VP9) | وب با پس‌زمینهٔ شفاف | دارد |
| MOV (ProRes 4444) | کامپوزیت در Premiere / After Effects | دارد |
| GIF | پیش‌نمایش سبک | ندارد |
| PNG sequence (zip) | هر فریم جداگانه، بالاترین کیفیت | دارد |

گزینه‌ها: fps، مقیاس ۱× یا ۲× (مثلاً 1280×720 → 2560×1440)، بازهٔ in/out، کیفیت. نوار پیشرفت تعداد فریم‌ها را نشان می‌دهد و در پایان لینک دانلود می‌آید.

> برای لایهٔ شفاف، پس‌زمینهٔ Stage را خالی بگذار (Properties → Stage → Background خالی) یا لایهٔ Background را مخفی کن، بعد WebM/MOV با گزینهٔ Transparent بگیر.

### ۴.۶ ذخیره و بازگشت
- هر تغییر خودکار در مرورگر ذخیره می‌شود (localStorage) و دفعهٔ بعد همان پروژه باز می‌شود.
- **Save** یک `.zip` کامل (کد + assetها + manifest) می‌دهد که دوباره Import می‌شود.
- **History** نسخه‌های قبلی را نشان می‌دهد: موقع باز کردن پروژه، بعد از هر تغییری که Claude داد، و هر وقت
  خودت **Save a version now** بزنی یک نسخه ذخیره می‌شود. **Restore** آن نسخه را برمی‌گرداند و با Undo
  هم می‌شود برگشت. نسخه‌ها فقط در همین مرورگر می‌مانند (حداکثر ۶۰ تا برای هر پروژه).

### ۴.۷ استوری‌بورد: قبل از هر ویدیوی جدید
هر ویدیوی جدید سه مرحله دارد و همه در پنجرهٔ **Storyboard** انجام می‌شود (اگر بسته بود، از نوار بالا بازش کن):

1. **انتخاب استایل:** Claude سه فریم نمونه می‌سازد، یعنی یک لحظهٔ مهم ویدیو با سه ظاهر کاملاً متفاوت. Claude
   این‌ها را از یک کتابخانهٔ ۱۱۷ استایلی (تبلیغاتی، دست‌کشیده، کاغذی، رترو، نئون، دیتا، کیهانی و …) و بر اساس
   موضوع، مخاطب و برند انتخاب می‌کند و اگر لازم باشد از آن هم فراتر می‌رود.
   - روی فریمی که دوست داری **Choose this style** بزن. می‌توانی یادداشت هم بنویسی («رنگ‌ها گرم‌تر»).
   - اگر هیچ‌کدام خوب نبود، **Try other styles** بزن تا استایل‌های تازه بسازد.
   - **رفرنس:** یک عکس یا ویدیو (تا ۴ فایل، هرکدام تا ۴۰ مگابایت) اضافه کن تا Claude ظاهر و ریتمش را تقلید کند.
     از ویدیو خودکار یک برگهٔ ۱۲ یا ۱۶ فریمی ساخته می‌شود تا Claude کل ویدیو را ببیند.
2. **استوری‌بورد:** Claude نماها را با همان استایل می‌چیند: زمان هر نما، چه چیزی حرکت می‌کند، متن روی تصویر، صدا،
   و طرح چند نمای اصلی. **Approve and make the video** را بزن یا با **Ask for changes** بگو چه چیزی عوض شود.
3. **ساخت:** بعد از تأیید، Claude ویدیو را می‌سازد، خودش Check می‌کند و پروژه به‌صورت لایه باز می‌شود.

تا قبل از ساخت می‌توانی برگردی و استایل دیگری انتخاب کنی. اگر در چت به Claude بگویی «دومی» یا «تأیید»،
خودش انتخابت را ثبت می‌کند. اگر استوری‌بورد نمی‌خواهی، در درخواستت بگو «بدون استوری‌بورد».

### ۴.۸ صدا
- دکمهٔ **Sound** در پنل لایه‌ها یک فایل صوتی از کامپیوترت، یا یکی از ۲۱ صدای آماده را در محل playhead
  اضافه می‌کند: افکت‌ها (whoosh، pop، click، ding، impact، riser، glitch و …) و سه موسیقی زمینه
  (beat-90، beat-120، pad).
- هر صدا یک لایه است: در تایم‌لاین جابه‌جا و کوتاهش کن. در Properties بلندی صدا، fade، نقطهٔ شروع و تکرار را تنظیم کن.
- دکمهٔ بلندگو کنار دکمهٔ پخش، پیش‌نمایش را بی‌صدا می‌کند (روی خروجی اثری ندارد).
- خروجی MP4، WebM و MOV صدا را دارد، داخل zip فریم‌ها فایل `audio.wav` می‌آید، و GIF بی‌صداست.

### ۴.۹ جابه‌جایی، اندازه، چرخش و کی‌فریم
- لایه را انتخاب کن و روی تصویر بکشش. گوشه‌ها اندازه را عوض می‌کنند و دستگیرهٔ بالا می‌چرخاند. با Shift حرکت
  روی یک محور می‌ماند و چرخش ۱۵ درجه‌ای می‌شود.
- در **Properties ← Transform** مقدار X، Y، Scale، Rotation و Opacity را ببین. دکمهٔ ◇ از جای فعلی playhead برای
  آن ویژگی کی‌فریم می‌گذارد. playhead را جلو ببر و مقدار را عوض کن (یا لایه را بکش) تا کی‌فریم بعدی ساخته شود.
  ◆ کی‌فریمِ همان لحظه را پاک می‌کند. منوی Easing نرمی حرکت را تعیین می‌کند و Reset همه را پاک می‌کند.
- کی‌فریم‌ها روی تایم‌لاین به شکل لوزی دیده می‌شوند. اگر کلیپ را جابه‌جا کنی، کی‌فریم‌ها هم با آن می‌روند.
- این تغییرات در کد به‌صورت `data-motion` ذخیره می‌شوند و Claude هنگام ویرایش دست به آن‌ها نمی‌زند.

### ۴.۱۰ کامنت روی تصویر
روی **Comment** بزن (یا کلید C)، روی همان جایی از تصویر که باید عوض شود کلیک کن و بنویس چه می‌خواهی («این
متن را بزرگ‌تر کن»). Claude زمان، نقطه و لایه را دقیق می‌گیرد. Escape از حالت کامنت بیرون می‌آید.

### ۴.۱۱ بررسی کیفیت (Check)
**Check** ویدیو را روی کامپیوتر خودت رندر می‌کند (بدون مصرف سهمیهٔ Claude) و این‌ها را پیدا می‌کند: متنی که از
کادر بیرون زده یا به لبه چسبیده، متن بریده یا روی هم افتاده، متن کم‌کنتراست یا خیلی ریز، متن فارسیِ چپ‌چین،
متنی که برای خواندن خیلی کوتاه روی تصویر است، و بخش‌های خالی یا ثابت. روی هر مورد کلیک کن تا به همان لحظه
و لایه بروی. **Ask Claude to fix** کل فهرست را برای Claude می‌فرستد.

## ۷. قواعد کدی که ویرایشگر انتظار دارد (برای وقتی خودت یا Claude کد می‌نویسید)

```jsx
import React from "react";
import { Stage, Sprite, useTime, useSprite, Easing, interpolate, animate } from "./animations.jsx";

export default function Scene() {
  const t = useTime();                       // مجاز: بیرون یا داخل Stage
  return (
    <Stage width={1280} height={720} duration={8} fps={30} background="#0b0b12">
      <Sprite start={0.5} end={4} data-layer-name="Title">
        {({ progress }) => (
          <h1 style={{ opacity: progress, transform: `translateY(${(1 - Easing.easeOutCubic(progress)) * 40}px)` }}>
            سلام
          </h1>
        )}
      </Sprite>
    </Stage>
  );
}
```

- حرکت فقط تابع زمان است: `useTime`, `useSprite`, `interpolate`, `animate`, `Easing`. بدون CSS transition/keyframes، بدون `setTimeout`/`Math.random`.
- ایمپورت‌های مجاز: `react`، `react-dom`، `lucide-react`، `three` (فقط ماژول اصلی three.js، بدون addonها)، `gsap` با پلاگین‌های `SplitText`، `DrawSVGPlugin`، `MorphSVGPlugin`، `MotionPathPlugin`، `CustomEase` و `TextPlugin` (مثلاً `gsap/SplitText`)، `./animations.jsx` و فایل‌های نسبی پروژه (`./Card.jsx`, `./styles.css`, `assets/logo.png`).
- GSAP: انیمیشن را فقط داخل `useGsapTimeline((tl) => { … })` در کامپوننتی داخل یک Sprite بساز. خود ویرایشگر تایم‌لاین GSAP را با زمان Sprite جلو و عقب می‌برد، پس اسکراب و خروجی دقیق است. زمان شروع و پایان Sprite روی تایم‌لاین قابل کشیدن است، ولی زمان‌بندی داخلی GSAP فقط در کد است. نمونهٔ آماده: **Kinetic type (GSAP)** در پنجرهٔ Import. لایسنس GSAP مثل بقیهٔ پروژه MIT نیست.
- سه‌بعدی واقعی: `<Three3D>` یک صحنهٔ three.js را به‌صورت **یک لایه** می‌کشد. `setup` صحنه را یک بار می‌سازد و `render(t, …)` در هر فریم دوربین و اشیا را فقط از روی زمان `t` تنظیم می‌کند (بدون `+=`، بدون `setAnimationLoop`). عنوان‌ها لایه‌های دوبعدی معمولی روی آن هستند. نمونهٔ آماده: **3D dolly** در پنجرهٔ Import.
- هر المان داخل Stage یک `data-layer-id` پایدار می‌گیرد (خودکار). نام دلخواه با `data-layer-name`.

| علامت | علت / راه‌حل |
|---|---|
| «Preview error: Unsupported import 'x'» | کد از پکیجی استفاده می‌کند که در پیش‌نمایش نیست. با Ask Claude بگو «بدون x بنویس» یا پکیج را به لودر اضافه کن. |

| بالای ویرایشگر نوشته «Claude is connected to another WeDo Claude Motion tab» | ویرایشگر در تب دیگری هم باز است و Claude با آن تب کار می‌کند. یا آن تب را ببند، یا در همین تب روی **Use this tab** بزن. |
| پورت 3000 اشغال است و سرور روی پورت دیگری بالا آمده | کاری لازم نیست. ابزارهای Claude پورت واقعی را خودشان پیدا می‌کنند. ویرایشگر را با همان آدرسی که سرور نشان می‌دهد باز کن. |
| تب Ask Claude می‌گوید «Claude Desktop · offline» | در اپ Claude بنویس «به موشن استودیو گوش بده». درخواست‌هایی که فرستادی در صف می‌مانند و بعد جواب می‌گیرند. |
| با تیک «Use API key» خطای کلید می‌گیری | کلید را در `.env.local` بگذار و سرور را دوباره اجرا کن. |
| Export خطای مرورگر می‌دهد | Chrome یا Edge نصب نیست یا در مسیر غیرمعمول است؛ `CHROMIUM_PATH` را بده. |
