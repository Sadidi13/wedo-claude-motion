# WeDo Claude Motion

**با Claude انیمیشن بساز، بعد لایه‌به‌لایه ویرایشش کن.**

از Claude یک ویدیو بخواه. Claude اول چند استایل و یک استوری‌بورد نشانت می‌دهد. وقتی تأییدشان کردی، ویدیو
در مرورگرت به‌صورت یک پروژه باز می‌شود که هر جزئش یک لایهٔ جداست. خودت تغییرش بده یا به Claude بگو چه چیزی
را عوض کند. در آخر خروجی MP4، WebM، MOV، GIF یا PNG بگیر، همراه با صدا.

- رایگان و متن‌باز (MIT)
- روی کامپیوتر خودت اجرا می‌شود و چیزی آپلود نمی‌شود
- با اشتراک Claude کار می‌کند و کلید API لازم ندارد

[English](README.md)

> این پروژه مستقل است و وابسته به Anthropic نیست. Claude علامت تجاری Anthropic است.

## نصب

نیازمندی‌ها: ویندوز، مک یا لینوکس، [برنامهٔ Claude](https://claude.ai/download)، و Chrome یا Edge
برای خروجی ویدیو.

### ساده‌ترین راه: نصب را به Claude Code بسپار

برنامهٔ Claude را باز کن، به تب **Code** برو (هر پوشه‌ای باشد فرقی ندارد) و این پیام را بفرست:

</div>

```text
Install WeDo Claude Motion on this computer and open it.
Follow "Steps for Claude" in https://github.com/Sadidi13/wedo-claude-motion/blob/main/INSTALL.md
```

<div dir="rtl">

هر بار که Claude اجازهٔ اجرای دستوری را خواست، تأیید کن. اگر ویندوز پرسید که Node.js نصب شود یا نه،
**Yes** را بزن. آخر کار ویرایشگر خودش در مرورگر باز می‌شود.

### ویندوز: فقط یک خط

از منوی Start برنامهٔ **PowerShell** را باز کن، این خط را در آن بچسبان و Enter بزن:

</div>

```powershell
irm https://raw.githubusercontent.com/Sadidi13/wedo-claude-motion/main/scripts/install-windows.ps1 | iex
```

<div dir="rtl">

- چیزهایی را که کم است خودش نصب می‌کند.
- روی دسکتاپ میان‌بُر **WeDo Claude Motion** می‌سازد.
- وقتی پرسید **Connect it now?**، Enter را بزن. از تو می‌خواهد برنامهٔ Claude را یک لحظه ببندی (روی
  آیکن Claude کنار ساعت راست‌کلیک کن و Quit را بزن). بعد خودش دوباره بازش می‌کند.

برای به‌روزرسانی، همین خط را دوباره اجرا کن. پروژه‌ها و تنظیماتت حفظ می‌شوند.

### Claude Code در ترمینال: پلاگین

</div>

```bash
claude plugin marketplace add Sadidi13/wedo-claude-motion
claude plugin install wedo-claude-motion@wedo-claude-motion
```

<div dir="rtl">

بعد در هر پوشه‌ای از Claude Code ویدیو بخواه. اگر برنامه هنوز نصب نشده باشد، Claude پیشنهاد می‌دهد اول نصبش کند.

### نصب دستی، یا روی مک و لینوکس

بخش «By hand» در [INSTALL.md](INSTALL.md#3-by-hand) را ببین. فقط پنج دستور است.

## روشن کردن

- **ویندوز:** روی میان‌بُر **WeDo Claude Motion** روی دسکتاپ دوبار کلیک کن.
- **مک و لینوکس:** در پوشهٔ `wedo-claude-motion` دستور `pnpm bridge start` را اجرا کن.

ویرایشگر در آدرس http://localhost:3000 با یک پروژهٔ نمونه باز می‌شود. در ویندوز، برنامه در پنجره‌ای به نام
«WeDo Claude Motion server» کار می‌کند که در نوار وظیفه کوچک شده است. برای خاموش کردن، همان پنجره را ببند.

## کار با Claude

**ساختن ویدیو:** از Claude بخواه، مثلاً «یک تیزر ۶ ثانیه‌ای برای کافه‌ام بساز». این‌جاها کار می‌کند:

- تب **Code**، وقتی پوشهٔ `wedo-claude-motion` را در آن باز کرده باشی (بدون هیچ تنظیمی)
- **چت معمولی Claude** و تب Code در هر پوشه‌ای، بعد از اینکه برنامهٔ Claude را یک بار وصل کردی. نصب‌کنندهٔ
  ویندوز این را پیشنهاد می‌دهد. اگر آن موقع رد کردی، بعداً روی `scripts\connect-claude-chat.cmd` دوبار کلیک کن.

هر ویدیوی جدید در سه مرحله ساخته می‌شود، در پنجرهٔ **Storyboard** ویرایشگر:

1. **استایل:** Claude سه فریم نمونه نشانت می‌دهد (یک لحظه از ویدیو با سه ظاهر مختلف). یکی را انتخاب کن یا
   استایل‌های دیگری بخواه. می‌توانی یادداشت بنویسی و یک عکس یا ویدیوی رفرنس هم بدهی تا Claude ظاهرش را
   از روی آن بسازد.
2. **استوری‌بورد:** Claude نماها را با همان استایل می‌چیند (زمان‌بندی، چه چیزی حرکت می‌کند، متن روی تصویر،
   صدا). تأییدش کن یا بگو چه چیزی عوض شود.
3. **ویدیو:** Claude آن را می‌سازد، بررسی‌اش می‌کند و به‌صورت لایه باز می‌شود. اگر استوری‌بورد نمی‌خواهی، بگو.

از خود ویرایشگر هم می‌شود ویدیوی جدید شروع کرد: **Ask Claude ← New scene**.

**تغییر دادن:** یکی از این دو راه:

- **به Claude بگو:** در همان گفتگو بنویس، مثلاً «عنوان را بزرگ‌تر کن».
- **از خود ویرایشگر:** لایه را انتخاب کن، تب **Ask Claude** را باز کن و تغییر را بنویس. بعد یکی از این دو کار:
  - در Claude بنویس **«کلاد موشن رو چک کن»**
  - **اتوپایلوت** را روشن بگذار تا همهٔ درخواست‌ها را خودش جواب بدهد. با میان‌بُر
    **WeDo Claude Motion - Autopilot** روشن می‌شود. برای اتوپایلوت باید
    [Claude Code](INSTALL.md#connect-claude) روی کامپیوتر نصب باشد.

- **کامنت روی تصویر:** روی **Comment** بزن (یا کلید C)، روی جایی که باید عوض شود کلیک کن و بنویس چه
  می‌خواهی. Claude زمان، نقطه و لایه را می‌گیرد.

هر تغییر یک قدم در ویرایشگر است و با Undo برمی‌گردد.

## داخل ویرایشگر

- **لایه‌ها و تایم‌لاین:** هر جزء یک لایه است. کلیپ‌ها را بکش تا زمانشان عوض شود.
- **جابه‌جایی، اندازه، چرخش:** لایهٔ انتخاب‌شده را روی تصویر بکش. گوشه‌ها اندازه را عوض می‌کنند و دستگیرهٔ بالا می‌چرخاند.
- **کی‌فریم:** در Properties ← Transform، دکمهٔ ◇ از جای فعلی تایم‌لاین X، Y، اندازه، چرخش یا شفافیت را انیمیت می‌کند.
- **صدا:** دکمهٔ **Sound** یک فایل صوتی یا یکی از ۲۱ افکت و موسیقی آماده (whoosh، pop، impact، riser، ding،
  beat و …) را به‌صورت لایه اضافه می‌کند که می‌شود جابه‌جا و کوتاهش کرد. خروجی ویدیو صدا را هم دارد.
- **Check:** ویدیو را روی کامپیوتر خودت رندر می‌کند و متن بریده‌شده، روی هم افتاده، کم‌خوانا یا خیلی کوتاه، و
  بخش‌های خالی یا ثابت را فهرست می‌کند. **Ask Claude to fix** فهرست را برای Claude می‌فرستد.
- **History:** هر تغییری که Claude می‌دهد به‌صورت یک نسخه ذخیره می‌شود و می‌توانی برگردانی‌اش.

## هزینه دارد؟

- **خود برنامه رایگان است.**
- **کار Claude از سهمیهٔ اشتراک Claude خودت کم می‌شود،** مثل هر پیامی که به Claude می‌فرستی. هزینهٔ جدا
  یا کلید API لازم نیست.
- **منتظر ماندن هیچ مصرفی ندارد.** ویرایشگرِ باز، گفتگویی که منتظر درخواست است، یا اتوپایلوت، تا وقتی
  درخواستی نفرستی چیزی مصرف نمی‌کنند.
- **هر درخواست کمی از سهمیه را مصرف می‌کند،** چه ویدیوی جدید باشد چه یک تغییر.
  - ویدیوی جدید سه مرحلهٔ کوتاه دارد (استایل، استوری‌بورد، ویدیو)، پس کمی بیشتر مصرف می‌کند، ولی همان چیزی را
    می‌گیری که تأیید کرده‌ای.
  - رندر، پیش‌نمایش، Check و خروجی گرفتن روی کامپیوتر خودت انجام می‌شوند و هیچ سهمیه‌ای مصرف نمی‌کنند.
  - اتوپایلوت با مدل پیش‌فرض Claude کار می‌کند. `pnpm autopilot --model sonnet` مصرف کمتری دارد.
  - در یک گفتگوی طولانی، هر درخواست بیشتر از اتوپایلوت مصرف می‌کند، چون اتوپایلوت هر بار از صفر شروع می‌کند.

## خروجی و ذخیره

- **Export:** گرفتن خروجی ویدیو (MP4، WebM با پس‌زمینهٔ شفاف، MOV ProRes 4444، GIF یا فریم‌های PNG)
- **Save:** دانلود پروژه به‌صورت فایل `.zip`
- **Import:** باز کردن پروژهٔ ذخیره‌شده، یا کدی که از Claude Design یا Claude Motion گرفته‌ای (فایل MP4 به لایه تبدیل نمی‌شود)

## امنیت

- برنامه فقط روی کامپیوتر خودت جواب می‌دهد (127.0.0.1). دستگاه‌ها و سایت‌های دیگر به آن دسترسی ندارند.
- جواب‌های Claude قبل از اعمال در ویرایشگر بررسی می‌شوند.
- **فقط پروژه‌هایی را Import کن که از آدم‌های مورد اعتماد گرفته‌ای.** هر پروژه کدی است که داخل ویرایشگر
  اجرا می‌شود، مثل باز کردن یک فایل HTML.

## اگر مشکلی پیش آمد

- **پیام «node» یا «pnpm» is not recognized:** پنجرهٔ PowerShell را ببند، یک پنجرهٔ جدید باز کن و همان خط را دوباره اجرا کن.
- **مرورگر باز نشد:** آدرس http://localhost:3000 را باز کن. اگر پورت 3000 اشغال باشد، برنامه پورت بعدی
  (3001، 3002 و …) را برمی‌دارد و پنجرهٔ سرور شمارهٔ آن را نشان می‌دهد.
- **خروجی ویدیو کار نمی‌کند:** Google Chrome یا Microsoft Edge را نصب کن.
- **حذف برنامه:** پوشهٔ `wedo-claude-motion` و دو میان‌بُر روی دسکتاپ را پاک کن. اگر برنامهٔ Claude را وصل
  کرده بودی، در Claude به Settings، بعد Developer، بعد Edit Config برو و بخش `motion-studio` را پاک کن.
