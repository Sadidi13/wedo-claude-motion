# Motion Studio

- Layer editor for Claude Motion scenes. Start with `README.md`; module contracts are in `docs/CONTRACTS.md`.

- Requests in this repo to make or change a video or animation go into the running editor through the
  Claude Desktop bridge. Follow the `motion-studio` skill (`.claude/skills/motion-studio/SKILL.md`);
  the design is in `docs/CLAUDE-DESKTOP.md`.
